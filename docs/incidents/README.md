# Incidents

Every missed promise gets a short write-up here: a forecast not published by
the deadline, a forecast never scored, or bad data that got through. Blameless,
and focused on what changes so it can't happen the same way again.

| Date | Summary | Impact | Write-up |
|---|---|---|---|
| | *No incidents yet. Live since 2026-10-14.* | | |

## Template

Copy to `YYYY-MM-DD-short-name.md`:

```markdown
# <title>

- **Date:** YYYY-MM-DD
- **Impact:** which delivery days, which promise was missed, for how long
- **Detected by:** alarm / person / report

## What happened
Timeline in Berlin time.

## Why
The cause, and why the safeguards didn't catch it sooner.

## What changes
Concrete follow-ups with links (PRs, ADRs). "Be more careful" is not a follow-up.
```
